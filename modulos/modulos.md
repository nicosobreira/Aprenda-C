# O que vou falar

- Separação de arquivos `.c` e `.h`. Por que é importante?
- Como compilar com mais de um arquivo.
- Usar o exercício do Caixa Eletrônico em Repetição como um caso base para explicar os perigos do DRY. Exemplo: criar uma nova função que atualize o saldo, sem se preocupar se está pegando ou tirando; mostrar que inicialmente faz sentido, mas a medida que o programa cresce deixar essas duas operações diferentes em um mesmo lugar não faz sentido (para sacar dinheiro o caixa precisa verificar se está vazio, etc).
